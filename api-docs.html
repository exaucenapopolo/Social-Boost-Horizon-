API Social Boost Horizon

Bienvenue dans la documentation officielle de l'API Social Boost Horizon, la plateforme SMM n°1 en Afrique. Intégrez nos services (followers, likes, vues, commentaires) directement dans vos applications. Toutes les réponses sont en JSON et les montants en XAF (FCFA).

Introduction

Vous accédez à un catalogue unifié de plusieurs milliers de services SMM. Chaque service dispose d'un identifiant unique service_id. Les prix sont calculés côté serveur et ne peuvent jamais être modifiés par le client.

URL de base
https://socialboosthorizon.com

Démarrage rapide

  1. Générer une clé API Sur votre profil, onglet Développeur, cliquez sur « Générer une clé API ». Copiez-la immédiatement.
  2. Vérifier le solde GET /api/v1/balance
  3. Consulter le catalogue GET /api/v1/services ou catalogue web
  4. Passer une commande POST /api/v1/order
# 1. Solde
curl https://socialboosthorizon.com/api/v1/balance \
  -H "X-Api-Key: votre_cle"

# 2. Catalogue
curl https://socialboosthorizon.com/api/v1/services \
  -H "X-Api-Key: votre_cle"

# 3. Commander
curl -X POST https://socialboosthorizon.com/api/v1/order \
  -H "X-Api-Key: votre_cle" \
  -H "Content-Type: application/json" \
  -d '{"service_id":"sbh_SBH1_1234","link":"https://instagram.com/user","quantity":1000}'

Authentification

Chaque requête doit inclure votre clé API dans l'en-tête HTTP X-Api-Key.

X-Api-Key: votre_cle_api
Sécurité importante
Ne placez jamais votre clé dans du JavaScript côté navigateur public. Stockez-la dans une variable d'environnement côté serveur.

Sources disponibles

GET/api/v1/sources

Retourne la liste des sources publiques disponibles (SBH1, SBH2, SBH3, SBH4) et le nombre de services par source.

À quoi servent les sources ?
Le catalogue regroupe des services provenant de plusieurs canaux techniques. Chaque canal est identifié par un code neutre (SBH1 à SBH4).
Si vous souhaitez ne revendre que les services d'un canal spécifique, filtrez vos requêtes sur ce code.

Réponse 200

200 OK
{
  "success": true,
  "sources": [
    { "code": "SBH1", "count": 4821 },
    { "code": "SBH2", "count": 2140 },
    { "code": "SBH3", "count": 3102 },
    { "code": "SBH4", "count": 2417 }
  ],
  "total": 12480
}
curl https://socialboosthorizon.com/api/v1/sources \
  -H "X-Api-Key: votre_cle"

Lister les services

GET/api/v1/services

Retourne le catalogue complet des services disponibles, en temps réel.

Format du service_id
Format : sbh_<SOURCE>_<numéro> (ex. sbh_SBH1_1234). Copiez-le tel quel.

Paramètres (query)

ParamètreTypeDescription
source optionnel string Filtre par source : SBH1, SBH2, SBH3 ou SBH4. Utile pour ne revendre que les services d'une source donnée.
catalog optionnel string Filtre par catégorie (ex. Instagram, TikTok).

Réponse 200

200 OK
{
  "success": true,
  "services": [
    {
      "service_id": "sbh_SBH1_1234",
      "provider": "sbh",
      "source": "SBH1",
      "name": "Instagram Followers [Real]",
      "category": "Instagram",
      "type": "default",
      "price_per_1000": 5000,
      "min": 100,
      "max": 10000,
      "refill": true,
      "cancel": false,
      "description": "Haute qualité, garantis 30 jours"
    }
  ],
  "total": 12480,
  "sources": ["SBH1", "SBH2", "SBH3", "SBH4"]
}

Filtrer par source

Pour ne revendre que les services d'une source spécifique, utilisez le paramètre source :

# Source SBH1 uniquement
curl "https://socialboosthorizon.com/api/v1/services?source=SBH1" \
  -H "X-Api-Key: votre_cle"

# Source SBH3 uniquement
curl "https://socialboosthorizon.com/api/v1/services?source=SBH3" \
  -H "X-Api-Key: votre_cle"

# SBH2 + catégorie Instagram
curl "https://socialboosthorizon.com/api/v1/services?source=SBH2&catalog=Instagram" \
  -H "X-Api-Key: votre_cle"
Source invalide
Si vous passez une source inconnue, l'API renvoie 400 avec la liste des sources valides.

Passer une commande

Crée une nouvelle commande. Le coût est calculé côté serveur et le solde débité atomiquement.

ParamètreTypeDescription

Codes d'erreur

Chaque erreur retourne un objet JSON avec success: false et un champ error.

CodeSignificationCause fréquente
200SuccèsRequête traitée.
400Requête invalideParamètre manquant, quantité hors bornes, source inconnue, solde insuffisant.
401Non authentifiéHeader X-Api-Key manquant ou clé invalide.
404IntrouvableCommande inexistante ou n'appartenant pas à votre compte.
500Erreur serveurErreur interne ou fournisseur indisponible.
Exemple d'erreur
{ "success": false, "error": "Clé API manquante ou invalide." }

Questions fréquentes

Comment recharger mon solde ?

Depuis votre compte sur le site (Mobile Money ou carte bancaire).

Puis-je filtrer les services par fournisseur ?

Vous pouvez filtrer par source via ?source=SBH1 à SBH4. Si vous voulez uniquement revendre les services d'une source, utilisez ce paramètre dans tous vos appels.

Puis-je utiliser la même clé depuis plusieurs serveurs ?

Oui. Une clé par application est recommandée.

Que se passe-t-il si une commande est annulée ?

Remboursement automatique.

Y a-t-il une limite de débit ?

Usage raisonnable attendu.

Puis-je appeler l'API depuis un navigateur ?

Non recommandé. Une clé exposée peut être volée.
