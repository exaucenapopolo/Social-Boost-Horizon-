API Social Boost Horizon

L'API Social Boost Horizon permet à votre backend (PHP, Node.js, Python…) de passer des commandes de services SMM (followers, likes, vues, commentaires) en programmatique. Toutes les réponses sont en JSON. La devise est XAF (FCFA).

Introduction

Vous accédez à un catalogue unifié de plusieurs milliers de services. Chaque service possède un service_id opaque à utiliser pour commander. Les prix sont calculés côté serveur et ne peuvent pas être modifiés par le client.

Base URL
https://socialboosthorizon.com

Démarrage rapide

  1. Générer une clé API Allez sur votre profil, onglet Développeur, puis cliquez sur « Générer une clé API ». Copiez-la immédiatement : elle ne sera plus jamais affichée.
  2. Vérifier le solde Appelez GET /api/v1/balance pour confirmer que votre clé fonctionne.
  3. Consulter le catalogue Appelez GET /api/v1/services ou consultez le catalogue web pour choisir un service_id.
  4. Passer une commande Appelez POST /api/v1/order avec service_id, link et quantity. 
# 1. Solde
curl https://socialboosthorizon.com/api/v1/balance \
  -H "X-Api-Key: votre_cle"

# 2. Catalogue
curl https://socialboosthorizon.com/api/v1/services \
  -H "X-Api-Key: votre_cle"

# 3. Commander
curl -X POST https://socialboosthorizon.com/api/v1/order \
  -H "X-Api-Key: votre_cle" \
  -H "Content-Type: application/json" \
  -d '{"service_id":"sbh_a1x_1234","link":"https://instagram.com/user","quantity":1000}'

Authentification

Chaque requête doit inclure votre clé API dans le header HTTP X-Api-Key.

X-Api-Key: votre_cle_api
Sécurité
Ne placez jamais la clé dans du JavaScript côté navigateur. Stockez-la dans une variable d'environnement côté serveur. En cas de fuite : révoquez et régénérez immédiatement.

Lister les services

GET /api/v1/services

Retourne le catalogue complet des services disponibles, en temps réel.

Format du service_id
Chaque identifiant est opaque au format sbh_<code>_<numéro>. Copiez-le tel quel depuis la réponse. Ne le modifiez jamais manuellement.

Paramètres (query)

ParamètreTypeDescription
catalog optionnel string Filtre par catégorie (ex. Instagram, TikTok). Insensible à la casse.

Réponse 200

200 OK
{
  "success": true,
  "services": [
    {
      "service_id": "sbh_a1x_1234",
      "provider": "sbh",
      "name": "Instagram Followers [Real]",
      "category": "Instagram",
      "type": "default",
      "price_per_1000": 5000,
      "min": 100,
      "max": 10000,
      "refill": true,
      "cancel": false,
      "description": "Haute qualité, garantis 30 jours"
    }
  ],
  "total": 12480
}

Champs de réponse

ChampTypeDescription
service_idstringIdentifiant à utiliser pour commander.
providerstringToujours "sbh" dans cette version.
namestringNom commercial du service.
categorystringCatégorie (Instagram, TikTok…).
typestringType technique (default, package…).
price_per_1000integerPrix en XAF pour 1000 unités.
min / maxintegerBornes de quantité.
refill / cancelbooleanFonctionnalités supportées.
descriptionstringDescription (peut être null).
 
curl "https://socialboosthorizon.com/api/v1/services?catalog=Instagram" \

import requests

    headers={"X-Api-Key": "votre_cle"},
    params={"catalog": "Instagram"}
)
print(r.json())
$ch = curl_init("https://socialboosthorizon.com/api/v1/services?catalog=Instagram");
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "X-Api-Key: votre_cle"
]);
echo curl_exec($ch);

  { headers: { "X-Api-Key": "votre_cle" } }
);
const data = await r.json();
console.log(data);

Passer une commande

POST /api/v1/order

Crée une nouvelle commande. Le coût est calculé côté serveur et votre solde est débité atomiquement.

Corps JSON

ParamètreTypeDescription
service_id requis string Identifiant obtenu via GET /api/v1/services.
link requis string URL cible (profil, publication, vidéo…).
quantity requis integer Quantité entre min et max du service.
comments optionnel string Uniquement pour les services de type « custom comments ».

Réponse 200

200 OK
{
  "success": true,
  "order_id": "SBH-AUTO-1042",
  "service": "Instagram Followers [Real]",
  "quantity": 1000,
  "price": 5000,
  "currency": "XAF",
  "balance": 10000,
  "status": "pending"
}
curl -X POST https://socialboosthorizon.com/api/v1/order \
  -H "X-Api-Key: votre_cle" \
  -H "Content-Type: application/json" \
  -d '{"service_id":"sbh_a1x_1234","link":"https://instagram.com/user","quantity":1000}'
import requests

r = requests.post(
    "https://socialboosthorizon.com/api/v1/order",
    headers={"X-Api-Key": "votre_cle"},
    json={"service_id": "sbh_a1x_1234", "link": "https://instagram.com/user", "quantity": 1000}
)
print(r.json())
$body = json_encode([
  "service_id" => "sbh_a1x_1234",
  "link" => "https://instagram.com/user",
  "quantity" => 1000
]);
$ch = curl_init("https://socialboosthorizon.com/api/v1/order");
curl_setopt_array($ch, [
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_POST => true,
  CURLOPT_POSTFIELDS => $body,
  CURLOPT_HTTPHEADER => [
    "X-Api-Key: votre_cle",
    "Content-Type: application/json"
  ]
]);
echo curl_exec($ch);
const r = await fetch(
  "https://socialboosthorizon.com/api/v1/order",
  {
    method: "POST",
    headers: {
      "X-Api-Key": "votre_cle",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      service_id: "sbh_a1x_1234",
      link: "https://instagram.com/user",
      quantity: 1000
    })
  }
);
console.log(await r.json());

Codes d'erreur

Chaque erreur retourne un objet JSON avec success: false et un champ error lisible.

CodeSignificationCause fréquente
200SuccèsRequête traitée.
400Requête invalideParamètre manquant, quantité hors bornes, service inexistant, solde insuffisant.
401Non authentifiéHeader X-Api-Key manquant, clé inconnue ou révoquée.
404Ressource introuvableCommande inexistante ou appartenant à un autre compte.
500Erreur serveurErreur interne ou fournisseur indisponible. Réessayez.
Exemple d'erreur
{
  "success": false,
  "error": "Clé API manquante ou invalide."
}

Questions fréquentes

Comment recharger mon solde ?

Le solde se recharge depuis votre compte sur le site (Mobile Money ou carte bancaire). L'API ne gère pas la recharge.

Puis-je utiliser la même clé depuis plusieurs serveurs ?

Oui. Nous recommandons une clé unique par application.

Que se passe-t-il si une commande est annulée ?

Le remboursement est automatique et crédité sur votre solde. Vérifiez via GET /api/v1/order/:orderId.

Y a-t-il une limite de débit ?

Un usage raisonnable est attendu. Les abus peuvent entraîner une suspension temporaire.

Puis-je appeler l'API depuis un navigateur ?

Non recommandé. Une clé exposée côté client peut être volée en quelques secondes. Utilisez un serveur intermédiaire.

Le message « Service introuvable » s'affiche, que faire ?

Le catalogue évolue. Rechargez la liste via GET /api/v1/services et sélectionnez un service de remplacement.
