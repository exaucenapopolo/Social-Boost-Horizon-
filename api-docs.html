API Social Boost Horizon

Bienvenue dans la documentation officielle de l'API Social Boost Horizon, la plateforme SMM n°1 en Afrique. Intégrez nos services (followers, likes, vues, commentaires) directement dans vos applications via une API REST sécurisée. Toutes les réponses sont au format JSON et les montants en XAF (FCFA).

Introduction

Vous accédez à un catalogue unifié de plusieurs milliers de services SMM. Chaque service dispose d'un identifiant unique service_id à utiliser pour commander. Les prix sont calculés côté serveur et ne peuvent jamais être modifiés par le client.

URL de base
https://socialboosthorizon.com

Démarrage rapide

  1. Générer une clé API Allez sur votre profil, onglet Développeur, puis cliquez sur « Générer une clé API ». Copiez-la immédiatement : elle ne sera plus jamais affichée en entier.
  2. Vérifier le solde Appelez GET /api/v1/balance pour confirmer que votre clé fonctionne.
  3. Consulter le catalogue Appelez GET /api/v1/services ou consultez le catalogue web pour choisir un service_id.
  4. Passer une commande Appelez POST /api/v1/order avec service_id, link et quantity. 
# 1. Solde
curl https://socialboosthorizon.com/api/v1/balance \
  -H "X-Api-Key: votre_cle"

# 2. Catalogue
curl https://socialboosthorizon.com/api/v1/services \
  -H "X-Api-Key: votre_cle"

# 3. Commander
curl -X POST https://socialboosthorizon.com/api/v1/order \
  -H "X-Api-Key: votre_cle" \
  -H "Content-Type: application/json" \
  -d '{"service_id":"sbh_a1x_1234","link":"https://instagram.com/user","quantity":1000}'

Authentification

Chaque requête doit inclure votre clé API dans l'en-tête HTTP X-Api-Key.

X-Api-Key: votre_cle_api
Sécurité importante
Ne placez jamais votre clé dans du JavaScript côté navigateur public. Stockez-la dans une variable d'environnement côté serveur. En cas de fuite, révoquez-la immédiatement depuis votre profil et générez-en une nouvelle.

Lister les services

GET /api/v1/services

Retourne le catalogue complet des services disponibles, en temps réel.

Format du service_id
Chaque identifiant est opaque au format sbh_<code>_<numéro>. Copiez-le tel quel depuis la réponse. Ne le modifiez jamais.

Paramètres (query)

ParamètreTypeDescription
catalog optionnel string Filtre par catégorie (ex. Instagram, TikTok).

Réponse 200

200 OK
{
  "success": true,
  "services": [
    {
      "service_id": "sbh_a1x_1234",
      "provider": "sbh",
      "name": "Instagram Followers [Real]",
      "category": "Instagram",
      "type": "default",
      "price_per_1000": 5000,
      "min": 100,
      "max": 10000,
      "refill": true,
      "cancel": false,
      "description": "Haute qualité, garantis 30 jours"
    }
  ],
  "total": 12480
}

Champs de réponse

ChampTypeDescription
service_idstringIdentifiant à utiliser pour commander.
providerstringToujours "sbh".
namestringNom commercial du service.
categorystringCatégorie (Instagram, TikTok…).
typestringType (default, package…).
price_per_1000integerPrix en XAF pour 1000 unités.
min / maxintegerBornes de quantité.
refill / cancelbooleanFonctionnalités supportées.
descriptionstringDescription (peut être null).
 
curl "https://socialboosthorizon.com/api/v1/services?catalog=Instagram" \
  -H "X-Api-Key: votre_cle"

Passer une commande

POST /api/v1/order

Crée une nouvelle commande. Le coût est calculé côté serveur et le solde débité atomiquement.

Corps JSON

ParamètreTypeDescription
service_id requis string Identifiant obtenu via GET /api/v1/services.
link requis string URL cible (profil, publication, vidéo…).
quantity requis integer Entre min et max du service.
comments optionnel string Uniquement pour les services « custom comments ».

Réponse 200

200 OK
{
  "success": true,
  "order_id": "SBH-AUTO-1042",
  "service": "Instagram Followers [Real]",
  "quantity": 1000,
  "price": 5000,
  "currency": "XAF",
  "balance": 10000,
  "status": "pending"
}
curl -X POST https://socialboosthorizon.com/api/v1/order \
  -H "X-Api-Key: votre_cle" \
  -H "Content-Type: application/json" \
  -d '{"service_id":"sbh_a1x_1234","link":"https://instagram.com/user","quantity":1000}'

Codes d'erreur

Chaque erreur retourne un objet JSON avec success: false et un champ error lisible.

CodeSignificationCause fréquente
200SuccèsRequête traitée.
400Requête invalideParamètre manquant, quantité hors bornes, solde insuffisant.
401Non authentifiéHeader X-Api-Key manquant, clé inconnue ou révoquée.
404Ressource introuvableCommande inexistante ou appartenant à un autre compte.
500Erreur serveurErreur interne ou fournisseur indisponible.
Exemple d'erreur
{
  "success": false,
  "error": "Clé API manquante ou invalide."
}

Questions fréquentes

Comment recharger mon solde ?

Le solde se recharge depuis votre compte sur le site (Mobile Money ou carte bancaire).

Puis-je utiliser la même clé depuis plusieurs serveurs ?

Oui. Nous recommandons une clé unique par application.

Que se passe-t-il si une commande est annulée ?

Le remboursement est automatique et crédité sur votre solde.

Y a-t-il une limite de débit ?

Un usage raisonnable est attendu. Les abus peuvent entraîner une suspension temporaire.

Puis-je appeler l'API depuis un navigateur ?

Non recommandé. Une clé exposée côté client peut être volée en quelques secondes.

Le message « Service introuvable » s'affiche ?

Le catalogue évolue. Rechargez la liste via GET /api/v1/services.
